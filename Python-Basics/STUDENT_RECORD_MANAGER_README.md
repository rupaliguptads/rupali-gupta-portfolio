# Student Record Manager - Python Mini Project

## Project Overview
Student Record Manager is a menu-driven Python application that helps manage student records.

This project is built using Python fundamentals and JSON file handling.

## Features
- Add new student records
- Display all student records
- Search students using Student ID
- Calculate average marks
- Validate student input
- Prevent duplicate Student IDs
- Store records permanently using JSON
- Load previously saved records when the program starts

## Technologies Used
- Python 3
- JSON
- pathlib

## Project Files
- `student_record_manager.py` - Basic version using dictionaries
- `student_record_manager_v2.py` - Advanced version with JSON storage
- `students.json` - Data file created automatically when records are saved

## How to Run

1. Download `student_record_manager_v2.py`.
2. Open the file using Python IDLE.
3. Press F5 to run the program.
4. Select an option from the menu.

## Menu Options
1. Add Student
2. Display All Students
3. Search Student
4. Calculate Average Marks
5. Exit

## Data Storage
The advanced version uses JSON to store student records permanently.

Student data remains available even after restarting the program.
