# Pandas and Exploratory Data Analysis (EDA)

My hands-on learning journey in Python, Pandas, and data analysis, with practical scripts and a complete student performance EDA project.

## Topics Covered

- Pandas Series and DataFrames
- Selecting rows and columns
- Data filtering and sorting
- Data cleaning and missing value handling
- Data analysis and aggregation
- GroupBy, merge, join, and concatenation
- Reading and writing CSV files
- Time series and pivot tables
- Statistical analysis
- Data visualization using Matplotlib

## EDA Concepts Practiced

- Dataset loading and initial inspection
- Dataset summary and descriptive statistics
- Data quality checks
- Missing value handling
- Duplicate record detection and removal
- Outlier detection using the IQR method
- Correlation analysis
- Grouped analysis and key insights
- Visualizations using histograms, bar charts, and scatter plots
